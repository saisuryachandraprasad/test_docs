APIs are one of the primary methods for accessing our data. Our APIs are comprehensive and support a broad range of use cases, from analytics to application development. We provide free access to the [Skills API](https://docs.lightcast.io/lightcast-api/reference/overview-skills)  and [Titles API](https://docs.lightcast.io/lightcast-api/reference/overview-titles)  so you can explore our Open Skills Library and understand the depth of our data.

## Free Access Features

Free API access allows you to:

* Query over 33,000 skills and 75,000 job titles.
* Access essential skill metadata such as names, IDs, types, and categories.
* Use autocomplete search and limited skill-extraction capabilities.
* Review taxonomy structures and updates.

This level of access enables you to analyze skills, build matching and search tools, and integrate structured data into your applications.

## How to Sign Up

1. Fill the [Registration form](https://lightcast.io/open-skills/access)  with necessary details and submit to initiate process.
2. You'll receive mail from us and follow the instructions to verify your email address.
3. Once your email is verified, you will receive your API credentials (Client ID and Client Secret) along with getting-started instructions.

## Ways to Explore the APIs

Once you have your credentials, you can begin exploring through:

| Method                                                                                           | Description                                             |
| :----------------------------------------------------------------------------------------------- | :------------------------------------------------------ |
| [Postman Collection](https://www.postman.com/lightcast)                                          | Inspect sample API calls and understand endpoint usage. |
| [Interactive API Reference](https://docs.lightcast.io/lightcast-api/reference/api-introduction)  | Review endpoints, parameters, and interactive examples. |

These tools help you learn how to authenticate, query, and integrate our APIs effectively.
