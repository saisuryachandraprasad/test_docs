APIs is one of the several ways to access our data. Our APIs were comprehensive and supports all your needs from analysis to building products. we are providing free access to Skills API and Titles API, enabling you to explore our comprehensive Open Skills Library and get the flavor of our data.

## What's Included with Free API Access

With free access, you can query and explore:

* More than 33,000 skills and 75,000 job titles in the Lightcast Open Skills Library.
* Skill metadata, including:
  * Skill names
  * Unique machine-readable identifiers
  * Skill types (specialized skills, common skills, and certifications).
* Category and subcategory details for each skill.
* Autocomplete search functionality.
* Limited access to skill extraction features.
* Direct access to each taxonomy with visibility into how it is structured and updated.

This access enables you to analyze skill relationships, build search and matching tools, and integrate structured skills data into your applications.

## How to Sign Up

1. Fill the [Registration form](https://lightcast.io/open-skills/access)  with necessary details and submit to initiate process.
2. You'll receive mail from us. Follow the instructions given in mail to verify your email.
3. Once your email is verified, you'll receive follow-up mail with API credentials (Client ID, Secret) and guides to proceed further.

## Ways to Explore the APIs:

After you receive your credentials, you can begin exploring in several ways:

* Postman collection: Use our Postman library to review our sample API calls.
* Interactive API Reference : Access our API Reference portal to view endpoints, parameters, and live examples.

These tools help you quickly understand how to authenticate, query, and integrate our APIs.
