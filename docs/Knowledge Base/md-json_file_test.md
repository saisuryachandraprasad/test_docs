# Canada Population Demographics

> Ready to use this data? See the Core LMI [reference documentation](/apis/core-lmi)  to get started.

## Description

This dataset contains population demographics data by area, age group, and gender. Historical data is available from 2001 to the current industry year and projected data from the current industry year to 2038. Data is available down to the Census Division level. Age is available in 18 categories including a totals category.

## Questions answered by this dataset

* What is the gender breakout of Vancouver?
* Has the millennial population in our area grown or declined over the past three years?

## Metrics

* Population: The number of people living in the area who match the given dimensions.
* ## Filters
  * Area (Nation, Province, Census Division)
  * Age (18 age bands)
  * Gender
  * Year
