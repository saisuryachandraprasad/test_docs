The Bureau of Labor Statistics (BLS) Employment Projections (EP) program publishes a wide range of datasets describing the U.S. labor force. These tables are updated annually and serve as key inputs into several Lightcast processes.
Lightcast uses the following EP datasets:

**Occupational Separations and Openings** ------cross link TBD

This dataset provides replacement rates, which Lightcast uses in its ***Openings calculations*** to estimate how many workers are needed to fill both new and existing positions vacated due to separations. ------ cross link TBD

**Educational Attainment for Workers Ages 25 and Older**

This table reports the percentage distribution of education levels attained by workers in each occupation. Lightcast uses this dataset as-is for its Educational Attainment breakouts within occupation profiles.

<Image border={false} />

**Education and Training by Occupation**

This dataset describes the typical entry-level education, required work experience, and on-the-job training associated with each occupation. These values are directly integrated into Lightcast’s occupational reports.

**National Industry-Occupation Employment Matrix (NIOEM)** -------- cross link TBD

The NIOEM provides projections linking industries and occupations. Lightcast uses this dataset to refine ***Industry*** projections, Staffing patterns, and Resulting occupational projections ---- cross link TBD
