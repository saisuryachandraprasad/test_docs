The Standard Occupational Classification (SOC) system is used by U.S. federal statistical agencies to classify workers into occupational categories for collecting, calculating, and disseminating labor-market data. The SOC system includes

* ~800 detailed occupations
* ~450 broad occupations
* ~95 minor groups
* 24 major groups

Detailed occupations are grouped based on job duties, and in some cases also by skills, education, or training.

**SOC Code Structure**

SOC codes use a hyphenated, four-tier hierarchy

| SOC Code | Level               | Description                                        |
| :------- | :------------------ | :------------------------------------------------- |
| 29-0000  | Major Group         | Healthcare Practitioners and Technical Occupations |
| 29-1000  | Minor Group         | Health Diagnosing and Treating Practitioners       |
| 29-1020  | Broad Occupation    | Dentists                                           |
| 29-1021  | Detailed Occupation | Dentists, General                                  |

Each additional digit increases the level of detail in the classification.

**SOC Updates and Lightcast Adoption**

The SOC system was updated in 2018. Lightcast adopted the 2018 SOC in 2022, following the transition of OEWS our primary earnings data source to the new version.
