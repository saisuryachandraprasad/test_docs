## Overview

This article explains how to update the CIP-to-SOC mapping, which applies to the U.S. SOC taxonomy.

> For Canada Analyst, the same process applies when updating the CIP-NOC mapping.

**Ways to Customize the CIP-to-SOC Mapping**

Users can tailor the program-to-occupation mapping in two main ways.

### Program Overview Report

* Run a Program Overview report on a detailed CIP code.
* Scroll to the Target Occupations section.
* Select Jump to Program to Occupation Mapping.

This opens a lightbox where you can

* Add occupations
* Remove occupations

Changes made here

* Apply to all other reports
* Persist across sessions
* Can be reset using Restore Default Occupations

<Image border={false} />

### Program to Occupation Mapping Report

* Open the Groups menu in the main navigation.
* Select Program to Occupation Mapping.

<Image border={false} />

The screen displays your current mappings and indicates whether each uses Default or Custom settings. To modify a program’s mappings

1. Select the Edit button.
2. Add or remove occupations as needed.
3. Save your changes mapping status updates to Custom.
4. Restore defaults anytime from the edit menu.

<Image border={false} />

**Sharing** or **Adopting Other Users’ Mappings**

A dropdown menu in the upper-left corner lists all Analyst users at your institution.

<Image border={false} />


By default, you view your mappings, but you can choose another user’s mappings and adopt them in one of two ways:

**Subscribe**

Links your account to another user’s mappings. Any future changes they make are automatically applied to your account.
Use this if a lead researcher manages mapping decisions for your institution.

**Overwrite**

Copies another user’s current mappings into your account one time. You may then customize or revert to defaults independently. Future changes made by the other user will not affect your account. This is useful when onboarding new staff.
